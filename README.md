# Shopify Free Sections

A free, open-source pack of ready-to-use **Shopify theme sections** for small stores, freelancers and independent designers.

Most Shopify apps that add simple things — an FAQ accordion, a size chart, trust badges — charge a monthly fee. These sections do the same job with **no app, no subscription and no tracking**: just copy one file into your theme and it appears in the theme editor like any built-in section.

## What's inside

| Section | What it does |
|---|---|
| `announcement-rotator` | Announcement bar that rotates up to 3 messages (free shipping, sale, delivery info) |
| `faq-accordion` | Clean FAQ accordion — add as many questions as you need from the editor |
| `size-chart` | Size conversion table (EU / US / UK / foot length in cm) — built for shoe & fashion stores |
| `trust-badges` | Row of trust badges: secure checkout, easy returns, fast delivery, support |
| `image-comparison` | Before / after image slider your customers can drag |

## How to use

1. In Shopify admin go to **Online Store → Themes → … → Edit code**
2. Under **Sections**, click **Add a new section** and paste the contents of any `.liquid` file from the `sections/` folder here (use the same file name)
3. Go to **Customize**, click **Add section**, pick the new section, and edit its text and colours — no coding needed

Every section is fully editable from the theme editor: text, colours, spacing and content blocks are all settings, not hard-coded values.

## Who this is for

- Small Shopify sellers who cannot justify another monthly app fee
- Freelance store designers who want reliable building blocks for client work
- Anyone learning how Shopify sections and schemas work
